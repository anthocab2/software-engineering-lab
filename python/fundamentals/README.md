This directory contains beginner Python practice focused on building the foundation needed for backend development.

The goal of this section is to practice the core concepts of Python through small, clear, and practical programs before moving into backend logic, data structures, JSON, APIs, databases, and testing.

## Current Files

### `employee_information.py`

A small command-line program that collects employee information from the user and displays it in a clean format.

Concepts practiced:

- `input()`
- Variables
- Type conversion with `int()`
- f-strings
- Basic formatted output
- Simple data organization

### `salary_calculator.py`

A small command-line program that calculates weekly and estimated monthly salary using an hourly rate and hours worked.

Concepts practiced:

- `input()`
- Variables
- Type conversion with `float()`
- Arithmetic operations
- f-strings
- Currency formatting

### `grade_average.py`

A small command-line program that calculates the average grade from multiple scores.

Concepts practiced:

- `input()`
- Variables
- Type conversion with `float()`
- Arithmetic operations
- Average calculation
- Formatted numeric output

### `product_summary.py`

A small command-line program that collects product information and calculates total inventory value.

Concepts practiced:

- `input()`
- Variables
- Type conversion with `float()` and `int()`
- Arithmetic operations
- f-strings
- Basic inventory-style thinking
